# Programa de estudio de algoritmos (Python)

Este repositorio contiene un entorno base para desarrollar material didactico por unidades.

## Estructura general

- `unidades/unidad-1-estructuras-de-datos-elementales`: Unidad implementada en Python con ejercicios, resultados y visualizaciones.
- `unidades/unidad-2-divide-y-conquista`: Estructura inicial para desarrollo futuro.
- `unidades/unidad-3-metodo-de-adquisicion`: Estructura inicial para desarrollo futuro.
- `unidades/unidad-4-programacion-dinamica`: Estructura inicial para desarrollo futuro.
- `unidades/unidad-5-ir-hacia-atras`: Estructura inicial para desarrollo futuro.
- `.cursor/rules`: Reglas activas para futuros desarrollos.
- `cursor/rules`: Carpeta de referencia solicitada.

## Requisitos

1. Python 3.10+.
2. Instalar soporte de interfaz grafica (Tkinter, una sola vez en Ubuntu/Debian):
   - `sudo apt-get install -y python3-tk`
3. Instalar dependencias:
   - `pip install -r requirements.txt`

## Ejecucion de Unidad I

1. Activar entorno virtual del proyecto:
   - `source .venv/bin/activate`
- Ejecutar todos los ejercicios:
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/main.py`
- Ejecutar interfaz interactiva de la unidad (uso y funcionamiento de conceptos):
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/visualizaciones/interfaz_unidad_1.py`
- Ejecutar programa grafico principal de la unidad:
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/visualizaciones/programa_grafico_unidad_1.py`
- Ejecutar ejercicios propuestos resueltos (archivos independientes):
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/ejercicios-propuestos/ejercicio_propuesto_01.py`
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/ejercicios-propuestos/ejercicio_propuesto_02.py`
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/ejercicios-propuestos/ejercicio_propuesto_03.py`
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/ejercicios-propuestos/ejercicio_propuesto_04.py`
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/ejercicios-propuestos/ejercicio_propuesto_05.py`
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/ejercicios-propuestos/ejercicio_propuesto_06.py`
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/ejercicios-propuestos/ejercicio_propuesto_07.py`
  - `python3 unidades/unidad-1-estructuras-de-datos-elementales/ejercicios-propuestos/ejercicio_propuesto_08.py`

## Estandar didactico obligatorio por unidad

1. Objetivo terminal.
2. Objetivos especificos.
3. Enunciados de diferentes ejercicios.
4. Resultado inmediato despues de cada enunciado.
5. Apoyo grafico para teoremas o conceptos clave.
