## Como ejecutar

Actualmente esta unidad no tiene scripts implementados.

Cuando se agreguen programas en esta unidad, usar este formato:

- Ejecutar programa principal:
  - `python3 unidades/unidad-4-programacion-dinamica/main.py`
- Ejecutar visualizaciones (si existen):
  - `python3 unidades/unidad-4-programacion-dinamica/visualizaciones/<archivo>.py`
