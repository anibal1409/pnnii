# UNIDAD II - Divide y conquista

## Objetivo terminal

Aplicar la estrategia Divide y Conquista para resolver busqueda, seleccion y ordenamiento de datos, comprendiendo sus pasos de dividir, conquistar y combinar.

## Objetivos especificos

- Implementar busqueda binaria recursiva e iterativa sobre listas ordenadas.
- Resolver maximo y minimo simultaneamente con enfoque Divide y Conquista.
- Ordenar listas con Merge Sort recursivo (top-down).
- Ordenar listas con Merge Sort iterativo (bottom-up).
- Ordenar listas con Quicksort usando particion de Lomuto y opcion mediana de tres.

## Contenido

- Ejercicio 1: Busqueda Binaria (consola y Tkinter).
- Ejercicio 2: Maximo y Minimo por Divide y Conquista (consola y Tkinter).
- Ejercicio 3: Merge Sort Recursivo (consola y Tkinter).
- Ejercicio 4: Merge Sort Iterativo (consola y Tkinter).
- Ejercicio 5: Quicksort (consola y Tkinter).
