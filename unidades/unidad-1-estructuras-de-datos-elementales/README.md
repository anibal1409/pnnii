# UNIDAD I - Estructuras de datos elementales

## Objetivo terminal

Al finalizar la unidad, el estudiante desarrolla competencias para evaluar conceptos relacionados con la representacion de algoritmos, arboles y heaps.

## Objetivos especificos

- Identificar problemas de optimizacion.
- Entender los conceptos de arbol, altura, nivel y grado.
- Diferenciar tipos de arboles (binarios y heap).
- Aplicar teoremas de arboles binarios para calculo de nodos y representacion secuencial.
- Construir arboles heap aplicando INSERTAR y HEAPIFY.

## Contenido

- Conceptos basicos de arbol, altura, nivel y grado.
- Tipos de arboles (binarios y heap).
- Teoremas I y II para arboles binarios.
- Algoritmos INSERTAR y HEAPIFY.

## Como ejecutar

1. Ubicarse en la raiz del proyecto:
   - `cd /home/anibal/Projects/PNNII`
2. Instalar dependencia de GUI (solo una vez en Ubuntu/Debian):
   - `sudo apt-get install -y python3-tk`
3. Activar entorno virtual del proyecto:
   - `source .venv/bin/activate`
4. Ejecutar todos los ejercicios de la unidad:
   - `python3 unidades/unidad-1-estructuras-de-datos-elementales/main.py`
5. Ejecutar la interfaz interactiva de la unidad (ejercicio grafico oficial):
   - `python3 unidades/unidad-1-estructuras-de-datos-elementales/visualizaciones/interfaz_unidad_1.py`
